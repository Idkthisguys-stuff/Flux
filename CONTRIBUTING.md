## Optimizing
Now, I have differnent types of optimizations for Flux, which are:

* **[Independency](#independency)**
* **[Performance](#performance)**
* **[Source code (Refactoring)](#source-code-refactoring)**
* **[Hardware](#hardware)**

### Independency
Indepenency is a type of optimization which strips a system (like the physics) out of its library, it usually turns a dependent system/class into an independent custom made system/class.

### Performance
Performance is a type of optimization where Flux is optimized for the performance and how well the engine runs.
